# Rehnumai

**Rehnumai** (Urdu for "Guidance") is an AI-powered educational assistant designed to empower teachers by providing them with a comprehensive, data-driven overview of their classroom. 

The application streamlines daily classroom management by offering a holistic **"Ustaad's Eye"** dashboard where teachers can instantly view a class heatmap, highlighting students categorized by performance or risk levels (Stable, Medium, High). Beyond just tracking attendance, it enables educators to easily log qualitative observations—such as academic progress and behavioral trends—and ultimately uses data-driven insights to help teachers tailor their interventions and provide better, individualized support for every student.

## Key Features

- **Darsgah (Dashboard)**: View your class status at a glance with the Ustaad's Eye heatmap, sorting students by their current risk and engagement levels.
- **Student Logging**: Log detailed observations for Attendance, Academics, and Behaviors directly from the dashboard.
- **Nazar (Analysis)**: Track reasoning trails and behavioral patterns over time to make informed decisions.
- **Amal (Interventions)**: Get actionable insights and suggested interventions tailored to specific student needs.
- **Teacher Profiles**: Personalized experiences with dark/light mode support and profile management.

## Tech Stack
- **Flutter**: Cross-platform UI toolkit.
- **Provider & SharedPreferences**: State management and local data persistence.
- **Google Generative AI**: AI integrations for analysis and insights.

## Getting Started

To run this project locally, ensure you have Flutter installed.

1. Navigate to the app directory:
   ```bash
   cd rehnumai
   ```
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the application:
   ```bash
   flutter run
   ```
